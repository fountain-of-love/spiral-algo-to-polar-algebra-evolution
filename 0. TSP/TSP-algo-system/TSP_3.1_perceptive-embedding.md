# 🌾 Stage 3-1 – Sensorium / Perceptive Embedding

---

## 🔹 Essence

**Sensorium** is the **awakening of awareness** inside the constructive process.

The system begins to **sense its own structure and surroundings** — distances, densities, angles, continuity — and adjusts behaviour based on feedback **from the field itself**.

In TSP heuristics, this appears when an algorithm becomes **context-aware**: it monitors local geometry, density, or direction and uses that sensory input to guide the next move.

It’s no longer a static rule; it’s an **active observation loop**.

---

## 🧩 1. Representative Algorithms / Mechanisms

| Family / Method | Core Mechanism | Behavioural Signature |
| :--- | :--- | :--- |
| **Adaptive Angular Ordering (early GAO variants)** | At each step, measure angular distribution of unvisited points and select within a rotating field. | **Orientation-aware**; smooth curvature; density-responsive. |
| **Density-Adaptive Sweep** | Adjust bin width or sweep rate based on local point density. | Balances uniform traversal speed; reduces crossings. |
| **Nearest Neighbor with Context Window** | Evaluate not only distance but angular deviation from current path. | **Curvature-aware**; avoids sharp turns. |
| **Insertion with Local Field Memory** | Use previous edge orientations and distances to bias next insertion. | Creates rhythm; learns local flow. |
| **Feedback-Weighted Greedy** | Apply weights from geometric coherence metrics ($\Delta\theta$, $\Delta r$) to guide selection. | **Sensory modulation** of greediness. |

* **Complexity:** $O(n \log n – n^2)$ depending on feedback sampling.
* **Performance:** near-insertion quality at quasi-greedy speed; strongly geometry-dependent.

---

## ⚖️ 2. Core Dualities of Sensorium

| Axis | Pole A | Pole B | Interpretation |
| :--- | :--- | :--- | :--- |
| **Sensing vs Acting** | measure environment | choose action | feedback loop replaces static rule. |
| **Local Signal vs Global Pattern** | read nearby cues | maintain overall orientation | constant calibration. |
| **Passive vs Active Perception** | observe | probe / perturb | exploration through motion. |
| **Continuous vs Discrete Feedback** | smooth metrics (angle, radius) | event-based corrections | different sensory modes. |
| **Internal vs External Reference** | memory of path | environmental geometry | self-referential sensing. |

$\text{Sensorium}$ thus transforms **awareness** into an algorithmic primitive.

### ✅ Stage 3-1 Summary

**Stage 3-1 – $\text{Sensorium}$ = The Law of Perceptive Embedding**

* **“The system feels its own form.”**
* **Purpose:** introduce awareness of environment and internal geometry.
* **Representative Algorithms:** Adaptive Sweeps, Early GAO, Context-Aware Greedy, Feedback-Weighted Insertion.
* **Structure:** perception-action feedback loop.
* **Energetic Pattern:** attentive, responsive, rhythmic sensing.
* **Outcome:** smoother, curvature-aware tours; coherence arising from feedback.
* **Transition Vector:** toward **$\text{Conformatio}$ (S.03-2)** when sensory feedback begins not only to **observe** but to **shape** — where awareness becomes craftsmanship.
