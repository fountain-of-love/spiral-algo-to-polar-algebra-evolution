# 🔨 Stage 3-2 – Conformatio / Crafted Transformation

---

## 🔹 Essence

**$\text{Conformatio}$** means **“to form together.”**

Here the system moves from **merely sensing** ($\text{Sensorium}$) to **actively shaping** — refining its internal geometry through deliberate modification.

This marks the birth of **agency and refinement**: the algorithm begins to mold itself in harmony with the sensed environment.

In TSP heuristics, this shows up in **locally improving** or **structurally refining** behaviour: edges are smoothed, crossings eliminated, and curvature minimized not through brute force but through **form-aware logic**.

---

## 🧩 1. Representative Algorithms / Mechanisms

| Family / Method | Core Mechanism | Behavioural Signature |
| :--- | :--- | :--- |
| **2-Opt / 3-Opt Local Refinement** | Swap edges if it shortens total distance. | **Craft-like optimization**; polishes structure locally. |
| **Angle-Constrained Greedy** | Avoid sharp turns by enforcing curvature thresholds. | Produces visually smooth, physically realistic tours. |
| **Adaptive Insertion with Curvature Penalty** | Penalize large angular deviations when inserting nodes. | Learns **curvature-aware flow**. |
| **Greedy + Rewire (GAO Refinement)** | Continuously realign local path segments to maintain rotation continuity. | Organic spiral refinement; **evolving craftsmanship**. |
| **Convexification / Smoothing Passes** | Adjust node ordering to restore convex envelope. | Builds global coherence through local reshaping. |

* **Complexity:** typically $O(n^2)$ (2-opt) to $O(n^3)$ (3-opt) refinement steps.
* **Performance:** closes the last 3–7 % gap from insertion heuristics; visually and geometrically coherent tours.

## ⚖️ 2. Core Dualities of Conformatio

$\text{Conformatio}$ thus merges **aesthetic and functional intelligence** — the system learns to **design itself**.

| Axis | Pole A | Pole B | Interpretation |
| :--- | :--- | :--- | :--- |

| **Local vs Global Form** | refine edges | maintain systemic harmony | micro-actions serve macro-order |
| **Correction vs Innovation** | fix existing path | create new alignment | refinement as creative act |
| **Static vs Dynamic Refinement** | one-time polishing | continuous evolution | form in motion |
| **Smoothness vs Efficiency** | prioritize curvature | prioritize cost | balance of elegance and performance |
