# 🧱 Stage 2-2 – Textura / Structural Scaffolds

---

## 🔹 Essence

**Textura** weaves the adaptive responses of Adaptatio into **repeatable structure**.

Instead of merely inserting smoothly, the algorithm starts **organizing space**—creating internal channels, clusters, or partial tours that act as **structural supports**.

In constructive TSP heuristics, this is where **segmentation**, **binning**, and **hierarchical pre-structuring** appear.

Textura = **“the fabric that holds the flow.”**

---

## 🧩 1. Representative Algorithms

| Family / Algorithm | Core Mechanism | Behavioural Signature |
| :--- | :--- | :--- |
| **Cluster-First, Route-Second (CFRS)** | Partition points (by k-means, angular bins, grid) $\to$ solve sub-tours $\to$ connect clusters. | Introduces **modular structure**; handles large $n$ efficiently. |
| **Angular / Spatial Binning** | Divide space into sectors or cells and route within each in sequence. | Builds repeatable lattice; very fast; **scalable**. |
| **Grid or Quad-Tree Partitioning** | Recursive spatial decomposition; solve locally, link globally. | **Multiscale scaffold**; adaptive density handling. |
| **Skeleton + Insertion** | Compute a convex-hull or spine; insert remaining points by Adaptatio logic. | Creates a **backbone**; organizes later flow. |
| **Voronoi / Delaunay Pre-Graph** | Generate geometric graph before tour construction. | Uses underlying mesh as support fabric; reduces search space. |

* **Complexity:** typically $O(n \log n + \text{sub-tour cost})$ — nearly linear per module.
* **Performance:** strong for structured datasets and large $n$; quality depends on clustering heuristic.

## ⚖️ 2. Core Dualities of Textura

| Axis | Pole A | Pole B | Interpretation |
| :--- | :--- | :--- | :--- |
| **Continuity vs Modularity** | continuous adaptation | discrete segments | tension between flow and fabric. |
| **Global vs Local Structure** | single pattern | nested scales | scaffolding spans levels of organization. |
| **Static vs Dynamic Grid** | fixed partition | adaptive partition | static frames vs live textiles. |
| **Density vs Uniformity** | cluster tight zones | even spread | how fabric absorbs spatial pressure. |
| **Topology vs Geometry** | connectivity | metric detail | shift from pure geometry to relational map. |

**Textura** thus **anchors** Adaptatio’s fluid sensitivity inside a stable, iterable mesh.

## 🔺 3. Triads Active in Textura

| Triad | Roles | Meaning / Manifestation |
| :--- | :--- | :--- |
| **(Module, Link, System)** | local cluster $\leftrightarrow$ inter-connector $\leftrightarrow$ whole tour | foundational structural triad. |
| **(Pattern, Density, Order)** | repetition $\leftrightarrow$ occupation $\leftrightarrow$ sequencing | defines textural character. |
| **(Backbone, Branches, Fills)** | main route $\leftrightarrow$ connectors $\leftrightarrow$ details | architectural analogy to scaffold building. |
| **(Rule, Exception, Adjustment)** | base pattern $\leftrightarrow$ local deviation $\leftrightarrow$ re-integration | self-correcting textile logic. |

These triads express **stability through interdependence** rather than single-point optimization.

### ✅ Stage 2-2 Summary

**Stage 2-2 – Textura = The Law of Structural Support**

* **“Flow becomes fabric.”**
* **Purpose:** stabilize adaptive flows by embedding them in modular scaffolds.
* **Representative Algorithms:** CFRS, Grid Partitioning, Convex-Hull Skeleton, Voronoi Graph.
* **Structure:** network of modules linked by rules of continuity.
* **Energetic Pattern:** integrative, constructive, scalable.
* **Outcome:** stable but adaptive tours; pre-ecological architecture ready for Stage 3 interaction.
* **Transition Vector:** toward **Stage 3 (Ecologia)** when modules start **interacting and co-regulating** their boundaries.
