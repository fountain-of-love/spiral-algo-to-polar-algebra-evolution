# 🌐 Algorithmic Evolution Lineages — The Nearest Neighbor (NN) Family

Every algorithm can be viewed as a **living lineage** — evolving from its primitive, greedy beginnings (Stage 1a) through containment (1b) and adaptive, flow-aware (2) refinements.  
The **xAO framework** interprets this as geometric evolution: from discrete polarity to continuous field awareness, and finally to adaptive texture.  

Below is the **evolutionary arc of the Nearest Neighbor (NN)** heuristic — one of the simplest constructive algorithms — as it matures across the Blueprint stages.

---

## 🧩 NEAREST NEIGHBOR (NN) Evolution

### **Algorithm NN-Classic (Stage 1a – Dualitas)**  
*Pure greedy local choice — no containment, no continuity.*

```python
Input: point set P
Output: tour π

1.  s ← argmin_p (x[p], y[p])             # deterministic start (e.g. leftmost)
2.  visited ← ∅;  π ← [s];  current ← s
3.  while |visited| < n:
4.      visited ← visited ∪ {current}
5.      S ← P \ visited
6.      next ← argmin_{p ∈ S} ||p − current||     # nearest neighbor
7.      current ← next;  append to π
8.  return π + [π₁]
```

### **Essence**
- **Perspective:** Single-point, locally optimal at each step.  
- **Blueprint Stage:** 1a (**Dualitas**) — active polarity, no containment.  
- **Complexity:** O(n²) (or O(n log n) with spatial indexing).  
- **Strengths:** Simplicity, speed.  
- **Weaknesses:** No global coherence; trapped in short loops or crossings.

---

### **Algorithm NN-Containment (Stage 1b – Trinitas)**
*Adds global ordering; still greedy but field-aware.*

```python
1.  C ← centroid(P)
2.  Sort P by polar angle θ[p] = angle(C → p)    # establish global containment
3.  s ← argmin_p ||p − C||                       # start near center
4.  θ ← θ[s];  visited ← ∅;  π ← [s];  current ← s
5.  while |visited| < n:
6.      visited ← visited ∪ {current}
7.      S ← NEAR_ANGLE_BIN(θ, ΔΘ, P \ visited)   # local region in sorted order
8.      if S = ∅ then S ← NEXT_NONEMPTY_BIN(P \ visited)
9.      next ← argmin_{p∈S} ||p−current||        # still pure distance
10.     θ ← θ[next];  current ← next;  append to π
11.  return π + [π₁]

```

**Shift from 1a → 1b:**  
- Introduces a **passive containment field** via global angular ordering.  
- The tour wraps smoothly, reducing chaotic jumps and crossings.  
- **Complexity:** Still O(n²), but spatial coherence improves path quality by ≈ 2–4%.

### **Algorithm NN-Adapt (Stage 2 – Adaptatio / Textura)**
*Flow-sustaining variant; adds structural feedback and adaptive bins.*

```python
1.  C ← centroid(P)
2.  Compute (r[p], θ[p]) for all p
3.  Create bins B[r, θ] with (Δr, ΔΘ)             # polar lattice texture
4.  s ← argmin_p ||p − C||;  θ ← θ[s]
5.  visited ← ∅;  π ← [s];  current ← s
6.  while |visited| < n:
7.      visited ← visited ∪ {current}
8.      S ← NEAR_TEXTURE_BIN(r[current], θ, Δr, ΔΘ, P \ visited)
9.      if S = ∅ then S ← NEXT_NONEMPTY_BIN(P \ visited)
10.     next ← argmin_{p∈S} [ ||p−current|| + α·|r[p]−r[current]| ]
11.     (Δr, ΔΘ) ← ADAPT_BIN_SIZES(local_density(P, current))
12.     θ ← θ[next];  current ← next;  append to π
13.  return π + [π₁]

```

**Stage 2 properties:**  
- Introduces **feedback:** bin sizes adapt to local density.  
- Penalizes **abrupt radial jumps (α term).**  
- Mimics *living flow* → smoother, balanced tours.  
- **Blueprint Stage:** 2 **Adaptatio / Textura** — structure sustains flow.  
- **Complexity:** ≈ O(n²), typically faster via bin pruning.
