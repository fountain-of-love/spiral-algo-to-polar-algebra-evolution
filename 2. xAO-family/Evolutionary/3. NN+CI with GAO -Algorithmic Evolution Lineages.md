# 🌐 NN & CI Lineages — Field and Textura Integration

This document applies the **evolutionary map** into concrete algorithmic blueprints, showing how the **Nearest Neighbor (NN)** and **Cheapest Insertion (CI)** families blend with the **GAO**.
Each algorithm is rebuilt using the same staged pattern — from **1a (Dualitas)** to **1b (Trinitas)** to **2 (Adaptatio/Textura)** — emphasizing compact pseudocode and key evolutionary deltas.
Lightweight optimizations and practical adaptation parameters are included for immediate implementation.

---

## 🧩 NN (Nearest Neighbor)

### **Algorithm NN-Classic — Stage 1a (Dualitas)**

```python
Input: point set P
Output: tour π

1.  s <- argmin_p (x[p], y[p])                 # deterministic start
2.  visited <- ∅;  π <- [s];  current <- s
3.  while |visited| < n:
4.      visited <- visited ∪ {current}
5.      S <- P \ visited
6.      next <- argmin_{p in S} ||p − current||
7.      current <- next;  append to π
8.  return π + [π[1]]
```

**Stage:** 1a pure greedy
**Complexity:** O(n²) (or O(n log n) with a k-d tree and lazy deletions)

---

### **Algorithm NN-Field — Stage 1b (Trinitas)**

```python
Input: point set P
Output: tour π

1.  C <- centroid(P)
2.  Sort P by polar angle θ[p] = angle(C → p)          # global rotational field
3.  s <- argmin_p ||p − C||                             # center seed
4.  θ <- θ[s];  visited <- ∅;  π <- [s];  current <- s
5.  while |visited| < n:
6.      visited <- visited ∪ {current}
7.      S <- NEAR_ANGLE_BIN(θ, ΔΘ, P \ visited)         # candidates in angular neighborhood
8.      if S == ∅: S <- NEXT_NONEMPTY_BIN(P \ visited)
9.      next <- argmin_{p in S} ||p − current||          # still pure NN inside the bin
10.     θ <- θ[next]
11.     current <- next;  append to π
12.  return π + [π[1]]
```

**Changed lines (vs. NN-Classic)**

* **2 — Sort by θ around C:** establishes a passive global containment; reduces chaotic zigzags and self-crossings.
* **3 — Start near center:** spirals outward, stabilizing directionality.
* **7–8 — Angular bins:** restricts candidates to a coherent sweep front → NN becomes field-aware.
* **10 — θ follows next:** maintains angular phase-lock for continuity.

**Stage:** 1b containment
**Complexity:** O(n²) but faster constants due to bin pruning.

### **Algorithm NN-Textura — Stage 2 (Adaptatio / Textura)**

```python
Input: point set P
Output: tour π

1.  C <- centroid(P)
2.  Compute polar coords (r[p], θ[p]) for all p
3.  Create lattice bins B[r, θ] with (Δr, ΔΘ)
4.  s <- argmin_p ||p − C||;  θ <- θ[s]
5.  visited <- ∅;  π <- [s];  current <- s
6.  while |visited| < n:
7.      visited <- visited ∪ {current}
8.      S <- NEAR_TEXTURE_BIN(r[current], θ, Δr, ΔΘ, P \ visited)
9.      if S == ∅: S <- NEXT_NONEMPTY_BIN(P \ visited)
10.     next <- argmin_{p in S} ( α * |r[p]−r[current]| + ||p−current|| )
11.     (Δr, ΔΘ) <- ADAPT_BIN_SIZES(local_density(P, current))
12.     θ <- θ[next];  current <- next;  append to π
13.  return π + [π[1]]
```

**Changed lines (vs. NN-Field)**

* **3 — Polar lattice (r, θ):** adds radial texture for smooth expansion.
* **8 — Texture neighborhood:** respects both angular and radial continuity.
* **10 — Radial drift penalty:** gently limits radius jumps → fewer spokes.
* **11 — Adaptive bin widths:** densify in clusters, widen in sparse zones.

**Stage:** 2 sustaining flow
**Complexity:** O(n²) with improved pruning; α ≈ 0.2–0.5 robust.

---

### **Quick NN Optimizations**

* Precompute distances in a compact triangular array for reuse.
* Use ring buffers for angular bins (O(1) rotation).
* Break ties by (θ, r) for determinism.
* Apply optional 2-opt on last K edges for a ~1–2% gain.

## 🧮 CI (Cheapest Insertion)

The **CI** lineage follows similar evolution — maintaining classic insertion semantics while progressively embedding field and texture awareness.

### **Algorithm CI-Classic — Stage 1a (Dualitas)**

```python
Input: point set P
Output: tour π

1.  s <- argmin_p (x[p], y[p]);  t <- argmax_p (x[p], y[p])
2.  π <- [s, t, s]                               # 2-node tour
3.  U <- P \ {s, t}
4.  while U != ∅:
5.      (u_star, i_star) <- argmin_{u in U, edge (π[i],π[i+1])} ΔC_insert(u, i)
6.      Insert u_star between (π[i_star], π[i_star+1])
7.      U <- U \ {u_star}
8.  return π
```

**Stage:** 1a local greedy insertion
**Complexity:** O(n³) naive; O(n²) with candidate pruning.

---

### **Algorithm CI-Field — Stage 1b (Trinitas)**

```python
Input: point set P
Output: tour π

1.  C <- centroid(P)
2.  Sort P by θ[p] = angle(C → p)                      # global rotational field
3.  s <- argmin_p ||p − C||;  t <- argmax_p ||p − C||  # inner–outer seed pair
4.  π <- ORDER_BY_ANGLE([s, t], θ) + [s]                # oriented 2-node loop
5.  U <- P \ {s, t}
6.  while U != ∅:
7.      Vθ <- TAKE_FROM_NEAR_ANGLE_FRONT(U, θ, π, ΔΘ)
8.      (u_star, i_star) <- argmin_{u in Vθ, edge (π[i],π[i+1])} ΔC_insert(u, i)
9.      Insert u_star between (π[i_star], π[i_star+1]);  U <- U \ {u_star}
10.     π <- REPHASE_TO_MAINTAIN_SWEEP(π, θ)
11.  return π
```

**Changes (vs. CI-Classic)**

* **2 — Angular ordering:** containment field, same as NN 1b.
* **3–4 — Oriented seeding:** stabilizes direction, avoids early long chords.
* **7 — Field-front candidate set:** prunes the search, enforces rotational continuity.
* **10 — Rephase sweep:** maintains continuity in θ.

**Stage:** 1b containment
**Complexity:** ~O(n²) effective.

### **Algorithm CI-Textura — Stage 2 (Adaptatio / Textura)**

```python
Input: point set P
Output: tour π

1.  C <- centroid(P)
2.  Compute (r[p], θ[p]) for all p;  make bins B[r, θ] with (Δr, ΔΘ)
3.  s <- argmin_p ||p − C||;  t <- argmax_p ||p − C||
4.  π <- ORDER_BY_ANGLE([s, t], θ) + [s]
5.  U <- P \ {s, t}
6.  while U != ∅:
7.      V <- NEAR_TEXTURE_FRONT(U, π, r, θ, Δr, ΔΘ)
8.      (u_star, i_star) <- argmin_{u in V, edge (π[i],π[i+1])} [ ΔC_insert(u, i)
9.                                     + β * | r[u] − r_mid(i) | ]
10.     Insert u_star between (π[i_star], π[i_star+1]);  U <- U \ {u_star}
11.     (Δr, ΔΘ) <- ADAPT_BIN_SIZES(local_density(P, u_star))
12.     π <- REPHASE_TO_MAINTAIN_SWEEP(π, θ)
13.  return π
```

**Changes (vs. CI-Field)**

* **2 — Polar texture bins:** radial weaving to augment containment.
* **7 — Texture-front:** restricts candidates by both r and θ.
* **8–9 — β penalty:** discourages radial kinks, smooths shell growth.
* **11 — Adaptive binning:** adjusts dynamically to local density.

**Stage:** 2 sustaining flow
**Complexity:** ~O(n²) with tight candidate set.

---

### **Quick CI Optimizations**

* Maintain best local candidate per edge (lazy updates).
* Cache ΔC for (u, i) and invalidate only affected entries.
* Use bucket queues keyed by θ-bin then ΔC for amortized O(1) insertion.
