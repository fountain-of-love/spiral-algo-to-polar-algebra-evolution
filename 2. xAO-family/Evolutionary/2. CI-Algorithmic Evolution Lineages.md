# 🧩 CHEAPEST INSERTION (CI) Evolution

The **Cheapest Insertion (CI)** family evolves alongside Nearest Neighbor (NN), moving from pure greedy incremental logic (**Stage 1a**) to field-aware containment (**Stage 1b**) and finally to adaptive structural flow (**Stage 2**). Each stage enhances geometric coherence under the xAO Blueprint.

---

### **Algorithm CI-Classic (Stage 1a – Dualitas)**

*Pure greedy incremental insertion.*

```python
Input: point set P
Output: tour π

1.  s <- argmin_p (x[p], y[p]);  t <- argmax_p (x[p], y[p])
2.  π <- [s, t, s]                        # initial 2-node tour
3.  U <- P \ {s, t}
4.  while U != ∅:
5.      (u_star, i_star) <- argmin_{u in U, edge (π[i], π[i+1])} ΔC_insert(u, i)
6.      Insert u_star between (π[i_star], π[i_star+1])
7.      U <- U \ {u_star}
8.  return π
```

**Stage:** 1a Dualitas — greedy incremental optimization
**Complexity:** O(n³) naive; O(n²) with candidate caching
**Behavior:** Builds local cost-optimal extensions; no field awareness.

---

### **Algorithm CI-Containment (Stage 1b – Trinitas)**

*Adds global angular order as a containment field.*

```python
1.  C <- centroid(P)
2.  Sort P by θ[p] = angle(C → p)
3.  s <- argmin_p ||p − C||;  t <- argmax_p ||p − C||
4.  π <- ORDER_BY_ANGLE([s, t], θ) + [s]
5.  U <- P \ {s, t}
6.  while U != ∅:
7.      Vθ <- TAKE_NEAR_ANGLE_FRONT(U, θ, π, ΔΘ)
8.      (u_star, i_star) <- argmin_{u in Vθ, edge (π[i],π[i+1])} ΔC_insert(u, i)
9.      Insert u_star between (π[i_star], π[i_star+1])
10.     U <- U \ {u_star}
11.     π <- REPHASE_TO_MAINTAIN_SWEEP(π, θ)
12.  return π
```

**Stage 1b Meaning:**

* Tour insertion happens within a rotating containment; global order stabilizes growth.
* Prevents erratic early insertions that break continuity.
* Often reduces runtime (fewer edges evaluated) and tour crossings.

### **Algorithm CI-Adapt (Stage 2 – Adaptatio / Textura)**

*Adds structural texture and adaptive feedback.*

```python
1.  C <- centroid(P)
2.  Compute (r[p], θ[p]) for all p; make bins B[r, θ]
3.  s <- argmin_p ||p − C||;  t <- argmax_p ||p − C||
4.  π <- ORDER_BY_ANGLE([s, t], θ) + [s]
5.  U <- P \ {s, t}
6.  while U != ∅:
7.      V <- NEAR_TEXTURE_FRONT(U, π, r, θ, Δr, ΔΘ)
8.      (u_star, i_star) <- argmin_{u in V, edge (π[i], π[i+1])} [ ΔC_insert(u, i) + β * |r[u]−r_mid(i)| ]
9.      Insert u_star between (π[i_star], π[i_star+1])
10.     U <- U \ {u_star}
11.     (Δr, ΔΘ) <- ADAPT_BIN_SIZES(local_density(P, u_star))
12.     π <- REPHASE_TO_MAINTAIN_SWEEP(π, θ)
13.  return π
```

**Stage 2 Properties:**

* Adds dual radial–angular continuity; insertions respect flow texture.
* The **β** term penalizes edges that disrupt shell continuity.
* Adaptive bins preserve proportional density.
* **Blueprint:** 2 Adaptatio/Textura — sustaining flow with structure.
* **Effect:** CI becomes aware of spatial rhythms → more organic tours.
